# PrintDock – Home Assistant add-on

Manage and monitor all your 3D printers – Bambu Lab, Snapmaker, Anycubic, Klipper/Moonraker, OctoPrint – right inside Home Assistant.

Verwaltung und Überwachung aller 3D-Drucker direkt in Home Assistant.
